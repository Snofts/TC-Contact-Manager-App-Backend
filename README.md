# 📇 Contact Manager Backend

A secure RESTful API built with Node.js, Express, MongoDB, and JWT to manage contacts with user-specific access, sharing, and Swagger docs.

---

## 🔧 Features

- User registration & login
- JWT-based authentication
- CRUD for personal contacts
- Share contacts with other users (read/edit)
- Input validation and sanitization
- Swagger UI for API documentation
